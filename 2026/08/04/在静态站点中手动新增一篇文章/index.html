在静态站点中手动新增一篇文章

发表于 2026-08-04 更新于 2026-08-04

本站是 Hexo + NexT 生成后推到 GitHub Pages 的静态产物。若本地已经找不到源工程，也可以按下面步骤继续发文。

需要改哪些文件

  1. 新增文章 HTML：按日期路径放置，例如 /2026/08/04/文章标题/index.html
  2. 更新首页 index.html：把新文章卡片插到列表最上方
  3. 更新归档页：archives/index.html 以及对应年份目录
  4. 更新本地搜索索引：在 search.xml 增加一条 entry
  5. 顺手把导航角标、侧栏「日志」数量从 4 改成 5

发布

提交并推送到 GitHub 后，Pages 会自动部署。合并到 master 即可在线上看到新页面。

长期维护仍建议找回 Hexo 源仓库；手动改静态页适合临时补一篇，不适合频繁写作。
